# Despensa Viva — Identidade visual e protótipos

## Nome

**Despensa Viva**

O nome comunica diretamente a ideia de uma despensa doméstica acompanhada continuamente.

## Proposta visual

A interface deve transmitir organização, alimentação e controle de estoque, sem excesso de elementos.

## Paleta

| Uso | Cor |
|---|---|
| Primária | `#2E7D32` |
| Secundária | `#66BB6A` |
| Destaque | `#F9A825` |
| Alerta | `#E53935` |
| Fundo | `#F7F9F7` |
| Texto | `#263238` |
| Branco | `#FFFFFF` |

## Tipografia

- **Títulos:** Poppins, semibold.
- **Texto:** Inter ou Arial, regular.
- **Fallback:** sans-serif.

## Assinatura visual

Texto "Despensa Viva" acompanhado de um símbolo simples associado a uma folha e/ou caixa de armazenamento.

## Telas essenciais

### 1. Login
- e-mail;
- senha;
- botão Entrar;
- acesso ao cadastro.

### 2. Painel
- quantidade total de itens;
- itens vencidos;
- itens a vencer em 7 dias;
- acesso rápido ao estoque;
- acesso ao relatório.

### 3. Estoque
- busca;
- filtros;
- lista de produtos;
- quantidade;
- local;
- validade;
- indicação visual de vencimento.

### 4. Cadastro de produto
- nome;
- marca;
- categoria;
- código de barras;
- botão para consultar Open Food Facts;
- dados nutricionais quando disponíveis.

### 5. Item de estoque
- produto;
- local;
- quantidade;
- unidade;
- validade;
- preço.

### 6. Relatório
- total de itens;
- produtos por categoria;
- itens vencidos;
- itens a vencer;
- movimentações;
- exportação CSV;
- impressão.
